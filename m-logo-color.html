Module 9: Color Fun with Turtle

মডিউল ৯: রঙের মেলায় টারটেল 🌈

Super Success Computer Education Center (SSCEC) – নতুন যুগের দিশারি

Pen Color Command (পেনের রঙ বদলানো)

টারটেলকে দিয়ে রঙিন ছবি আঁকতে আমরা SETPC (Set Pen Color) কমান্ড ব্যবহার করি। প্রতিটি রঙের জন্য একটি করে নম্বর আছে। To draw in color, we use the SETPC command. Each color has its own special number!

SETPC 0 (Black)
SETPC 1 (Blue)
SETPC 2 (Green)
SETPC 4 (Red)

Today's Activity (রঙিন মিশন)

চলো আমাদের শেখা অক্ষরগুলোকে রঙিন করি। অক্ষরটি আঁকার আগে রঙের কমান্ডটি দিতে হবে। Let's color our letters! Type the color command before you start drawing the letter.

Letter M = Blue

কমান্ড: SETPC 1

Draw M after setting color to 1.

Letter S = Green

কমান্ড: SETPC 2

Draw S after setting color to 2.

Letter W = Red

কমান্ড: SETPC 4

Draw W after setting color to 4.

Fun Tip (মজার টিপস)

তুমি কি জানো? লোগোতে SETPC 5 লিখলে কি রঙ হয়? লিখে পরীক্ষা করে দেখো তো! Do you know what color SETPC 5 is? Try it and find out!
